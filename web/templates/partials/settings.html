第一次设置？按这 6 步来（大约 10 分钟）
  1. 打开 Google Cloud 控制台，新建一个项目（名字随便取，不需要开通结算）。
  2. 在「API 和服务 → 库」里启用 Google Analytics Data API、Google Analytics Admin API 和 Google Search Console API。
  3. 在「IAM 和管理 → 服务账号」里创建服务账号，不要给它任何角色。记下它的邮箱（形如 xxx@项目ID.iam.gserviceaccount.com）。
  4. 点进服务账号 →「密钥 → 添加密钥 → 创建新密钥 → JSON」，下载密钥文件。Google 提示“建议改用工作负载身份联合”时直接继续即可。
  5. 在 GA「管理 → 账号访问权限管理」里，把服务账号的邮箱加为查看者（加在账号这一层，下面所有媒体资源都能看到）。
  6. 在 Search Console 里，每个网站「设置 → 用户和权限 → 添加用户」，把同一个邮箱加为受限用户。

默认值是怎么定的、各档是什么意思？

默认值：洞察不思考（数据已经全写在提示里，只是归纳成几条结论）；问答少想；诊断和报告正常思考（要自己决定查什么、把几份数据对起来找原因）。把结论整理成固定格式这类小调用始终不思考。

各档怎么换成参数：

服务商不思考少想正常多想
通义千问 / 阿里百炼关开，思考预算 1,024开，思考预算 4,096开，不限
DeepSeek关lowhigh（它的默认）max
OpenAI、Gemini、Grok、OpenRouterlow（关不掉）lowmediumhigh
小米 MiMo、智谱、豆包关开（只有开和关）

思考预算是一次调用里最多“想”多少 token，平时一次只用 400～2,500，这两个上限只挡住偶尔想个没完的情况。

“自动”认得的接口：阿里百炼、DeepSeek、OpenAI、Gemini、Grok、OpenRouter、小米 MiMo、智谱、火山方舟。其他接口（包括各种中转网关）默认不带任何思考参数，需要的话在上面手动选一种写法。

通义千问要注意两点：qwen-plus 思考和不思考的输出价格不一样（思考贵 4 倍），而这里的输出价格只能填一个，按任务开关思考时计费会有偏差，建议用 3.x 系列（两种模式同价）；qwen3.7-flash 这类按单次请求的输入长度分档计价的模型，价格填第一档的即可，Pingoo 的单次请求平时在 1.5 万 token 以内。

保存后点下面的“测试”：服务商不认识的参数，有的会忽略、有的会直接报错。

这里填的 JSON 会原样加进发给这个模型的每一次请求，用来打开或关闭服务商特有的功能。不知道填什么就留空。
什么时候要填？

上面的“思考强度”覆盖不到的情况才需要：比如服务商控制思考的写法不在列表里，或者要打开别的特有功能。这里写的参数和思考强度的参数同名时，以这里为准（所有任务都用同一个值）。

注意：不能填 model、messages、tools 这些字段（由 Pingoo 决定）；服务商不认识的参数，有的会忽略、有的会直接报错，所以保存后一定点下面的“测试”，三项都正常再给用户用。Pingoo 已经给每次调用设了 16,000 token 的输出上限（防止偶尔失控），一般不用再填 max_tokens；填了以你填的为准，填得太小回答会被截断。不想用了清空再保存即可。
